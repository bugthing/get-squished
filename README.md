Get Squished!
=============

A game about cute little animals avoiding feet that want to squish them, their ownly
defence, agility and water balloons.

Written in ruby using the dragon-ruby engine this 2d game was developed with my 8 year old daughter.



## Controls

- **Arrow keys** — move left / right
- **Spacebar** — throw water balloon (max 3, refills every 5 seconds)

## How to play

Survive as long as possible without getting squished by the descending feet.
Water balloons slow down feet on hit, but become less effective the longer you survive.
New feet appear every 20 seconds. Everything speeds up over time.

## Audio

Sound effects and music files go in the `sounds/` directory. Supported formats: `.wav` and `.ogg`.

| File | Event |
|---|---|
| `sounds/music.ogg` | Background music (loops) |
| `sounds/poof.wav` | Balloon fired |
| `sounds/splat.wav` | Balloon hits foot |
| `sounds/thud.wav` | Foot stomps floor |
| `sounds/squish.wav` | Player squished |
| `sounds/game_over.wav` | Game over jingle |
| `sounds/high_score.wav` | New high score chime |
